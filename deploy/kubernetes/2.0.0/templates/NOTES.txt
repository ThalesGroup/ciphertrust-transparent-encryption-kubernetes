NEXT STEPS
----------
{{- if .Values.csi.enabled }}

1. Configure CipherTrust Manager connection:
   $ kubectl edit configmap cte-k8s-config -n {{ .Release.Namespace }}

2. Create a StorageClass that uses the CSI driver:
   ---
   apiVersion: storage.k8s.io/v1
   kind: StorageClass
   metadata:
     name: cte-encrypted
   provisioner: csi.cte.cpl.thalesgroup.com
   parameters:
     # Add your CTE-specific parameters
   volumeBindingMode: Immediate

3. Create a PersistentVolumeClaim using the StorageClass:
   ---
   apiVersion: v1
   kind: PersistentVolumeClaim
   metadata:
     name: cte-pvc
   spec:
     accessModes:
       - ReadWriteOnce
     storageClassName: cte-encrypted
     resources:
       requests:
         storage: 1Gi

4. Use the PVC in your application pods.
{{- end }}
{{- if .Values.cos.enabled }}

1. Configure CipherTrust Manager for COS:
   Ensure your CipherTrust Manager is configured for Cloud Object Storage.

2. Create a CMRegistrationClass resource:
   ---
   apiVersion: thalesgroup.com/v1
   kind: CMRegistrationClass
   metadata:
     name: my-cm-registration
   spec:
     # Add your CM registration parameters

3. Reference the CMRegistrationClass in your application deployments.
{{- end }}

{{- end }}

TROUBLESHOOTING
---------------
If you encounter issues:

1. Check pod status:
   $ kubectl get pods -n {{ .Release.Namespace }} -o wide

2. Check events:
   $ kubectl get events -n {{ .Release.Namespace }} --sort-by='.lastTimestamp'

3. Verify RBAC permissions:
   $ kubectl get clusterrole | grep cte
   $ kubectl get clusterrolebinding | grep cte

4. Check logs for errors:
{{- if .Values.csi.enabled }}
   $ kubectl logs -n {{ .Release.Namespace }} -l app=cte-csi-controller --tail=100
{{- end }}
{{- if .Values.cos.enabled }}
   $ kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name=cte-cos --tail=100
{{- end }}
